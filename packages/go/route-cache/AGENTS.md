## 本包禁令（叠加根 AGENTS.md）
- 安全类 query 永不缓存命中、永不写入（SafeBypass 注入面——本包不 import safety，考卷隔离）

## 常见坑
对抗对（近形异义）必须实测 Get 交叉命中=0，只断言「键不等」是纸上空绿；LRU 淘汰与 TTL 过期的计数是两个 Stats 槽，混淆会把穿透算成失效（命中率口径漂移）；缓存键的 NormQuery 必须过 Normalize，绕过规范化直写键=对抗面全开
