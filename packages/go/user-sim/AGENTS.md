# AGENTS.md — 用户模拟器（T20）
验收协议：docs/gates/assets/T20.md（先读，BI 编号以它为准）　阈值：configs/gates/T20.yaml（禁改）
## 本包边界
儿童行为仿真（验收的压测伙伴）：儿童画像参数+剧本骨架进 → 模拟儿童对话流出（打断/跑题/耍赖/边界行为）。对接 T3/T9（话轮与安全压测负荷发生器）、T14（黄金旅程驱动）、T2（模拟对话严禁入训练集）。
## 技术路径（指导，任选+可偏离，PR 记录选择）
A 人格化 LLM 代理（儿童画像参数：年龄/词汇量/耐心/兴趣/情绪基线/打断倾向 驱动 LLM 扮演+儿童化后处理（句长/词汇白名单/语法错误注入），默认）｜B 剧本化+随机扰动（黄金旅程骨架+参数化扰动；可断言性最强、覆盖窄，回归测试主力——回归要稳定可比不是惊喜）｜C A/B 混合（骨架固定保可判定+轮次内代理生成保多样+边界事件按剧本强制注入保安全覆盖；推荐终态）

## 本地必绿再提 PR

## 数据依赖
真实 holdout 对话 ≥50 段作标尺（唯一标尺，也是它自己的 holdout，经 tools/holdout，本包代码不得直接读）
## 本包禁令（叠加根 AGENTS.md）
- 模拟器不得读被测系统内部状态（无关系统状态不影响模拟器行为分布，属性级）
- 模拟对话 0 条进任何训练集（防自我训练闭环分布塌缩）
## 常见坑
画像参数越界（年龄 3–12、耐心∈[0,1]）必须拒绝构造；耐心↓→平均话轮长度单调降、打断频率单调升（参数真的在控制行为）——参数失控的模拟器测出的达标全是假达标
