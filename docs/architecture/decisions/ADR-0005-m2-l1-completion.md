# ADR-0005 M2 L1 完全体：纯 Go 规则面先行 + BAML 提示词纯落盘 + T20 真 driver 只测不训
状态：accepted 2026-08-29（IR #89，规格=docs/m2-spec.md）
背景：M2 交付六域（T2 负样本音景/T9 安全/T7 情绪/T12 动作映射/T8 人格/T20 driver+预算接线，实现卡 #90–#95），但 BAML 编译器与 onnxruntime/Llama Guard 3 属重依赖（无 license 台账、目标硬件未定，须 founder 批），LLM 生成人格/对话不可断言（违反 T8/T20 属性面）。
决策：M2 全部以纯 Go 规则面落地——T9=词表+语境分级地板层（降级安全不降）、T7=OCC 显式规则+衰减动力学（全符号可断言）、T12=显式映射表+安全盒、T8=确定性编译（同卡同哈希）、T20=剧本化确定性生成；BAML 首批提示词（人格段/安全话术段/情绪标签段）纯文本落盘 baml/prompts，Go 侧不接线；T20 真 driver 只驱动 journeys 对 loop 真管道回放，产物禁入任何训练集（T20-G0-01）。
备选否决：现在接 BAML 编译器/onnxruntime（重依赖引入=founder 决策，越权）；用 LLM 生成人格与对话（不可断言面扩大，T8-G1-02..04、T9-G0-04、T20-G1-01 保持 debt 至 LLM 面经批准落地）。
后果：L1 六资产（T2/T4/T7/T8/T9/T12/T20）全部 G0/G1 门禁可 CI 真测（m2-spec §10 Mark 表 36 ID：真实 24/debt 12）；LLM/真机/真实数据面债务显式可见可追踪，重依赖批准后按 §10 注记逐条升级复测。
